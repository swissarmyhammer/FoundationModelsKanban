## What
divergence.md M9 "checkLinks and repairLinks". After `checkLinks` (^rctvtvc) finds old-name links, `repairLinks` corrects them.

## Do
- `repairLinks(boards:, reach:, dryRun:)` rewrites each **old name** link to the current name of the board (git key when there is one, else the ULID).
- It writes only to the named boards. `reach: true` also writes to the boards that the scan can reach.
- It is a normal transaction: one `undo` reverses it. `dryRun: true` lists the changes and writes nothing.
- It does not change a **dangling** link. It reports it.

## Acceptance Criteria
- [ ] A `dependsOn`, an assignee URI, a body task URL, and a tombstone line with an old name are rewritten.
- [ ] One `undo` puts back each rewritten link.
- [ ] `dryRun: true` writes nothing and lists the same changes.
- [ ] A board that the call does not name is not changed unless `reach: true`.
- [ ] Tests use temporary folders and temporary git repos only.
