## What
divergence.md Q12 as changed by P4 (DECIDED), N5, and §11 "Q12 (changed by P4)". This is work on the Swift package (S/ = Sources/FoundationModelsKanban/). Code: S/GraphQL/NameMatcher.swift, S/GraphQL/NameRewrite.swift.

Problem (N5): the error message for a name that does not match suggests only names with a similar spelling. It does not list the fields of the type. A removed Rust parameter gives a general validation error with no "use X" hint.

Decided behavior (final):
- A removed Rust parameter is ignored. The call runs, and the response gets a warning in `extensions.warnings` with the text "`<name>` is removed, use X". The removed parameters (P4 list) and their hints:
  - `project` → removed; use tags.
  - `due`, `scheduled` → removed; no replacement (write the date in the body).
  - `exclude_done` (`excludeDone`) → removed; use the filter `!#DONE`.
  - `page` → removed; use `first` and `after` (cursor paging).
  - `detail` → removed; choose the fields in the selection set.
  - `include_counts` (`includeCounts`) → removed; select `summary` (or `totalCount`).
  - `attachments` → removed; no replacement.
  - Note: `model` is not in this list, because the board `model` field is added back (Q19). `avatar` is not a Rust MCP parameter.
- Accept each removed name in its case and style forms (snake_case and camelCase).
- A name that matches nothing still fails. The error lists the canonical field names of that type (all of them), in addition to the near-spelling suggestions.
