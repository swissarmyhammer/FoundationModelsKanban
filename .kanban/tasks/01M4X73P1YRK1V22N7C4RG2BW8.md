## What
divergence.md R17 (§1.1, §11 bugs). This is work on the Swift package (S/ = Sources/FoundationModelsKanban/).

Problem: the agent cannot learn about dependencies between repos. The design makes introspection the way to learn the schema, but the schema has no field descriptions (S/GraphQL/Schema.swift:862). Thus introspection does not tell that `dependsOn` takes a full `kanban://` URI of a different board. The tool description does not mention dependencies between repos.

Change:
- Add a short sentence to the `KanbanTool` description: a task can depend on a task in another repo; give the full `kanban://<board-key>/task/<id>` URI in `dependsOn` or as a task URL in the body; a short form always names the current board (or the `board:` board).
- Add GraphQL descriptions to the schema types and fields, at least: `Task.dependsOn`, `Task.blockedBy`, `Task.unresolvedDependsOn` (when present), `Task.ready`, `Task.virtualTags`, `AddTaskInput.dependsOn`, `UpdateTaskInput.dependsOn`, the `board` arguments, `nextTask`, and the `filter` arguments (name the sigils `#tag @actor ^id %column ~type`). Write the descriptions in short, plain sentences.
- Keep the descriptions short so that the tool description and SDL stay small.
