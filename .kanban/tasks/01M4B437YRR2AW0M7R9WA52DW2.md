    Design choices that plan.md does not state:
    1. The default subcommand has the name `run`. ArgumentParser needs a subcommand type for `defaultSubcommand`, so `kanban run '<document>'` also works. `kanban '<document>'` and `kanban --schema` go to `run`.
    2. `kanban '<document>'` builds `KanbanArguments` from a `GeneratedContent` with the keys `query` and `variables`, and calls `KanbanTool(graph:).call(arguments:)`. Thus the library owns the decode of `--variables`. Text that is not one JSON object gives a response with `INVALID_VARIABLES` and the exit status 0 (plan.md §7.1). A subscription document through `run` gives `SUBSCRIPTION_NOT_IN_TOOL`; `watch` is the path for a subscription.
    3. `watch` has no `--variables` option, because plan.md §7.2 names none. It calls `subscribe` with no variables.
    4. The root of the engine is the current directory as it is. The CLI does not search for the git top-level directory. The session actor is the OS user (`actor: nil`).
    5. Bad arguments exit with `EX_USAGE` (64): no document and no `--schema`, a document together with `--schema`, and `--variables` without a document. An I/O fault (for example a directory that is not in a git repo) exits with `EXIT_FAILURE` (1).
    6. SIGINT: `signal(SIGINT, SIG_IGN)` plus a `DispatchSource` signal source that feeds an `AsyncStream`. A child task of a task group waits for the first element and calls `graph.close()`; the close ends the subscription stream, and the command exits with 0. ## What
The command line tool. The basis is plan.md §7.2 (CLI) and §6.7 (In the CLI).
- `Sources/kanban/KanbanMain.swift` with swift-argument-parser:
  - `kanban '<document>' [--variables <json>]`: run against the current directory; print the response JSON.
  - `kanban watch '<subscription>'`: print one JSON line for each event until the user stops it (SIGINT ends the stream and calls `close()`).
  - `kanban --schema`: print the generated SDL.
- Exit code 0 for a response (also with GraphQL errors); a non-zero code only for an I/O fault or bad arguments.
