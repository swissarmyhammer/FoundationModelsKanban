## What
The command line tool. The basis is plan.md §7.2 (CLI) and §6.7 (In the CLI).
- `Sources/kanban/KanbanMain.swift` with swift-argument-parser:
  - `kanban '<document>' [--variables <json>]`: run against the current directory; print the response JSON.
  - `kanban watch '<subscription>'`: print one JSON line for each event until the user stops it (SIGINT ends the stream and calls `close()`).
  - `kanban --schema`: print the generated SDL.
- Exit code 0 for a response (also with GraphQL errors); a non-zero code only for an I/O fault or bad arguments.

## Acceptance Criteria
- [ ] `kanban '{ board { name } }'` in a temporary repo prints a response with the directory name.
- [ ] `kanban --schema` prints SDL that has `type Task` and no `patch` field.
- [ ] `kanban watch` prints one line for a commit made by a second process.
