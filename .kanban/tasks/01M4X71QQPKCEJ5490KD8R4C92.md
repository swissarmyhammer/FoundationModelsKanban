## What
divergence.md Q2 (DECIDED), X2, and §11 "Q2". This is work on the Swift package (S/ = Sources/FoundationModelsKanban/).

Problem (X2): `dependsOn` and `blockedBy` drop each target that no loaded board has, but `ready` stays false. Example: a typo in the URI, a missing repo, or an old key after a repo move. The task is BLOCKED with `blockedBy: []`, and the agent cannot see which URI to remove.

Decided behavior:
- Add the field `Task.unresolvedDependsOn: [ID!]!`. It lists each `dependsOn` target (from edges and from body markers) that no loaded board has, as a full `kanban://` URI.
- `blockedBy` stays `[Task!]!`.
- A target that cannot resolve still blocks the task (§3.3 rule 4: an unknown target counts as not done).
- A tombstoned target is not unresolved: it is ignored, as now.
- Targets on a related board that cannot be read (Q7) also show here.

Change the code: S/GraphQL/QueryResolvers.swift:512-536 and S/GraphQL/Schema.swift.

## Acceptance Criteria
- [x] A task with a URI to a missing repo lists that URI in `unresolvedDependsOn` and is BLOCKED.

- [x] A task with only resolved targets has `unresolvedDependsOn: []`.
- [x] A tombstoned target is not in `unresolvedDependsOn`.
